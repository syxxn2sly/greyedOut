3. FUNCTIONS AND TARGET AUDIENCE

Greyed Out is an offline daily planner for people whose available energy
varies day to day — the audience is broadly people with ADHD, chronic
fatigue, or similar, though nothing in the app is diagnostic or specific
to any condition.

The problem it solves: conventional planners assume today's user is the
same person who wrote yesterday's list. When that is not true, the list
becomes a source of guilt and gets abandoned.

Greyed Out opens with one question — "how do you want today served?" —
with three answers: "regular", "the blunt list", and "i can't today".
That answer determines how much the app puts on screen. In regular mode
it shows the next three tasks, food and water logging, a generated
schedule, and movement. In low-capacity mode it shows three items total
and hides everything else until the user asks for it back.

The value: the plan scales down to what the user actually has, instead
of the user failing to meet a fixed plan. Effort counts as completion
throughout — the focus timer's exit button reads "bail, still counts".

The app makes no health claims. It does not diagnose, treat, monitor, or
measure anything. Medication appears only as a user-set time of day used
to anchor the schedule, the same way lunch does. It has been declared as
not a regulated medical device.


4. SETUP AND ACCESS

No setup is required and no credentials are needed. There is no account,
no login, and no paid or gated content. Every feature is reachable on
first launch.

First launch shows a one-time screen for setting five times of day
(wake, meds/breakfast, lunch, workout, wind-down), each adjusted with
the arrow buttons. Tapping "that's my day" completes setup. After that
the app opens on the daily check-in.

The one permission prompt is calendar access, requested only if the user
taps Edit day > "import a calendar". It is optional; the app is fully
functional if it is denied, and only the import feature is unavailable.
Calendar data is read only, copied onto the device, and never written
back or transmitted.


5. EXTERNAL SERVICES

None. The app uses no external services, data providers, authentication
services, payment processors, or AI services.

It makes no network requests of any kind. All data is stored on the
device using local storage. There is no server, no account system, no
analytics SDK, no crash reporting, and no advertising. This is why the
App Privacy answer is "no data collected".

The only system framework used is EventKit, via Apple's iOS calendar
APIs, for the optional read-only calendar import described above.


6. REGIONAL DIFFERENCES

None. The app functions identically in all regions. There is no
region-specific content, no region-gated features, and no server that
could vary by locale.


7. REGULATED INDUSTRY / THIRD-PARTY MATERIAL

The app does not operate in a regulated industry and includes no
protected third-party material.

It is not a medical device and has been declared as such. It provides no
diagnosis, treatment, dosage calculation, or physiological measurement,
and makes no health claims. Medication is handled only as a user-entered
time of day.
